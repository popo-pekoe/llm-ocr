> **【AIへの指示用プロンプト文】**
> これから子供向けのWebアプリを作成（または修正）してください。
> 今回の開発は、**Cloudflare Pages（GitHub Publicリポジトリ連携）および Cloudflare Functions** の構成で行います。
> APIキーを安全に隠蔽するため、以下の仕様を厳格に守ってコードを生成してください。
> **1. ディレクトリ構造と出力ファイル**
> 以下の2つのファイルをコードブロックを分けて完全なコードで出力してください。
> * `index.html`（フロントエンド画面、Vanilla JS ＋ Tailwind CSS CDN）
> * `functions/api.js`（Cloudflare Functions用のバックエンド中継処理）
> 
> 
> **2. `functions/api.js` の実装ルール**
> * 最新の `@google/genai` の仕様に準拠してください。
> * フロントエンドから `POST` でリクエストを受け取ります。
> * APIキーは `context.env.GEMINI_API_KEY` から安全に取得し、`new GoogleGenAI({ apiKey: ... })` を初期化してください。
> * モデルは `gemini-2.5-flash` を使用し、生成されたテキスト（`response.text`）のみを JSON 形式でフロントエンドに送り返してください。
> * コード内には、ロジックの区切りがわかりやすいよう日本語で適切なコメントアウトを記述してください。
> 
> 
> **3. `index.html` の実装ルール**
> * 子供向けとして、見た目が非常に美しく楽しいモダンなUI（Tailwind CSS）にしてください（レスポンシブ対応必須）。
> * Gemini APIを呼び出す際は、外部のURLを直接叩いたりSDKをインポートしたりせず、自サイトの絶対パス `/api` へ `POST` リクエストを送るように JavaScript を記述してください。
> * 送信データは `{ prompt: "..." }` の形式、受け取るデータは `{ text: "..." }` の形式に統一してください。
> * こちらも、後から私が可読性を維持できるよう、UIのパーツごとに日本語で分かりやすいコメントアウト（例: `` など）を積極的に記述してください。
> 
>
